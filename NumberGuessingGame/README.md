# NUMBER GUESSING GAME

### Welcome to the **Number Guessing Game**, a fun interactive Python program where a player tries to guess a random number in the range of 1 to 100.

# Getting started

## How it works

In this game, the computer will randomly select a number between **1** and **100**

- **Easy level:** You have 10 attempts to guess the correct number.
- **Hard level:** You have 5 attempts to guess the correct number.

The program will give you hints whether your guess is too high or too low after each attempt.

## Rules

1. The computer will randomly pick a number between **1 and 100**.
2. The player selects a difficulty level: **Easy** (10 attempts) or **Hard** (5 attempts).
3. The player guesses the number.
4. The program will indicate if the guess is too high or too low.
5. The player keeps guessing until they either:
   - Guess the correct number, or
   - Run out of attempts.
6. If the player guesses correctly, they win. Otherwise, the computer reveals the number after all attempts are used up.

## Example

Here is an example of how the game might go:

```bash

I'm thinking of a number between 1 and 100.
Choose a difficulty level: 'easy' or 'hard': easy

You have 10 attempts remaining to guess the number.
Make a guess: 50
Too high.

You have 9 attempts remaining to guess the number.
Make a guess: 25
Too low.

You have 8 attempts remaining to guess the number.
Make a guess: 35
Too high.

You have 7 attempts remaining to guess the number.
Make a guess: 30
Congratulations! You guessed the number 30 correctly!

```
